# North Star Moment Coach Digest impact evaluation

*Run on 2026-09-26; see [Results](#results). All results are AI review of
synthetic Personas, not human validation.*

## What we are evaluating

We want to know whether adding the North Star Moment makes the Coach Digest
better. The [selection experiment](nsm_experiment_methodology.md) already shows
that Twinkl usually picks the right quotation, but not whether that quotation
improves the reflection the user reads. A better reflection should connect the
week's Conflict to something the user actually did for their Core Value,
without softening the Conflict or treating the moment as proof of recovery.

## The selection experiment

The [selection experiment](nsm_experiment_methodology.md) tested how Twinkl
picks a North Star Moment across 501 weeks from 105 synthetic Personas, using
AI review to judge whether each displayed quotation was correct. Reviewing the
Persona's full eligible writing chose a correct quotation for 72 of 86 scored
final-set cards (83.7%).

## Methodology

### Which weeks: 72

The selection experiment covered 501 weeks from 105 Personas, split by Persona
into a development set (81 Personas) and a final set (24 Personas, 110 weeks).
In the final set, Twinkl displayed a North Star Moment in 94 weeks; 86 of those
could be scored, and the AI review confirmed 72 as correct quotations.

We use those 72 weeks. Restricting to correct quotations measures the effect of
a good North Star Moment rather than mixing in selection mistakes, which the
selection experiment already counts. We use the final set because it was not
used to tune anything.

Before the main run, a pilot judges the 22 saved demo pairs from the
[demo comparison](demo_coach_comparison.md). They already exist, so the pilot
needs no new generation, and it checks that the judge gives consistent verdicts
before the 72 final pairs are generated.

### Pairs

For each week, we generate two Coach Digests from identical input: one with the
North Star Moment and one without it. The model, prompt, and Weekly Drift
Detection output stay the same, so any difference comes from the moment.
Both are generated by the model Twinkl actually uses for the Coach Digest,
OpenAI's `gpt-5.6-luna`, through the OpenAI API, so the evaluation measures
the product rather than a stand-in.

[`nsm_impact_generate.py`](../../scripts/experiments/nsm_impact_generate.py)
builds each week's Weekly Drift Detection input the way the live runtime does,
then generates and exports the pairs. The dry run needs no API calls. `--execute`
makes the 144 paid calls, and `--export` writes the pairs that
`nsm_impact_pilot prepare --pairs` turns into blinded judge tasks.

### Judge

The judge is Claude Opus 5.5 (`claude-opus-5-5`), run as Claude Code
subagents under a Claude subscription, the same way the project generated its
synthetic Journal Entries and judge labels. No API calls are needed for judging.

The judge comes from a different provider than the OpenAI model that wrote the
Coach Digests. This avoids a model favouring text written in its own style;
[Feng et al. (2026)](https://arxiv.org/pdf/2606.28960) found exactly this
self-preference when GPT-5.5 judged its own answers. Claude did write the
synthetic Journal Entries, but both Coach Digests quote the same entries, so
this does not favour either one.

The judge sees the week's Journal Entries, the Journal Entry the North Star
Moment came from, the Weekly Drift Detection result, and both Coach Digests
labelled only "Response 1" and "Response 2". It is not told which one had the
North Star Moment. It picks the one that better grounds the reflection in the
user's own action for the Core Value, or calls a tie.

Each subagent starts with no knowledge of Twinkl, so its instructions define
every term it will see, including Journal Entry, Core Value, Conflict, Drift,
Active Drift, No Active Drift, and Coach Digest. The week's facts are restated
in plain language rather than in the internal format used to generate the Coach
Digests, and the task omits the person's name, which the judgment does not need.

AI judges tend to favour whichever response appears in a particular position.
So each pair is judged twice with the order swapped, and the verdict counts
only if both orders agree; otherwise the week is a tie. Each order is judged
by a separate subagent, so the first verdict cannot influence the second, and
the files it reads contain no arm names or other clue to which response had
the moment.

Subagent runs do not produce per-call token receipts or fixed sampling
settings the way API calls do. Each verdict is therefore saved as its own file,
the run's manifest records the judge's model, effort, prompt version, and a hash
of its instructions, and results state that the judge ran through Claude Code
rather than the API.

### Metric

Each week ends as a **win** (the version with the North Star Moment is
preferred), a **loss** (the version without it is preferred), or a **tie**.

The headline metric is the **win difference**, the primary endpoint used by
[Feng et al. (2026)](https://arxiv.org/pdf/2606.28960) for blinded pairwise
comparisons:

```
win difference = (wins − losses) / weeks, in percentage points
```

For example, 40 wins, 14 losses, and 18 ties give (40 − 14) / 72 =
**+36.1 points**. Wins, losses, and ties are reported alongside it.

**How to read it:**

- **Baseline, 0.** The North Star Moment wins as often as it loses. This is the
  result expected if adding the moment makes no difference.
- **Floor, −100.** The version without the North Star Moment is preferred in
  every week.
- **Ceiling, +100.** The version with the North Star Moment is preferred in
  every week.
- **Ties pull the score toward zero.** With 18 ties out of 72 weeks, the most
  the score can reach is ±75, so a large tie count limits it.
- **+36.1 in plain terms.** Out of every 100 weeks, the version with the North
  Star Moment wins about 36 more than it loses. Here it won 40 weeks and lost
  14, so it was preferred almost three times as often.
- **Is that good?** For scale, Feng et al. found that the best clinical AI tool
  beat general-purpose models with win differences of 25 to 39 points, which
  they reported as a clear advantage. A score in that range would be a large
  effect. Their judges were physicians rather than AI, so this is a rough
  reference, not a threshold.

The size of the score only matters if it is reliably above zero. Weeks from the
same Persona are related, so the 95% range around the win difference is
estimated by resampling whole Personas. The North Star Moment counts as an
improvement only if that whole range is above zero. For example, +36.1 with a
range of +20 to +50 is a clear improvement, but +10 with a range of −5 to +25
is not.

### Honesty check

The judge also answers yes or no for each Coach Digest: does it soften or
excuse the Conflict, or present the moment as proof of recovery? The metric is
the **percentage of Coach Digests flagged** in each version. The improvement
stands only if the version with the North Star Moment is not flagged more often.

## Results

Both runs used the `nsm-impact-judge` Claude Code subagent (`claude-opus-5-5`,
effort medium, prompt `nsm-impact-judge-1.0`). Each Coach Digest pair was
judged twice with the order swapped, by separate subagents, with no reruns
needed. Subagent runs have no per-call token receipts.

### Summary

| | Pilot | Main run |
| --- | ---: | ---: |
| Weeks | 22 saved demo pairs | 72 final-set weeks |
| Personas | 5 | 23 |
| Same verdict in both orders | 18/22 | 61/72 |
| Response 1 vs Response 2 among decisive judgments | 19 vs 21 | 52 vs 56 |
| Wins / losses / ties | 16 / 2 / 4 | 36 / 12 / 24 |
| Win difference | +63.6 | **+33.3** |
| 95% Persona-resampled range | [+48.0, +82.4] | **[+19.4, +45.5]** |
| Flagged: with the North Star Moment | 3/44 | 2/144 |
| Flagged: without it | 7/44 | 0/144 |

The main run's 72 weeks cover 23 of the 24 final-set Personas; one Persona had
no correct card. Its Coach Digests came from `gpt-5.6-luna` at reasoning
effort `none`, the live Coach Digest model, in 203 calls costing US$0.155. Every
Coach Digest passed the usual Coach Digest Validations; a failed attempt was
retried with the failure reasons, and both versions needed retries about
equally (first-attempt pass: 52/72 with the moment, 48/72 without).

**Main run by North Star Moment mode and weekly state:**

| | Weeks | Wins | Losses | Ties |
| --- | ---: | ---: | ---: | ---: |
| Encouragement | 58 | 27 | 11 | 20 |
| Reflection | 7 | 2 | 1 | 4 |
| Reminder | 7 | 7 | 0 | 0 |
| No Active Drift | 65 | 34 | 11 | 20 |
| Active Drift | 7 | 2 | 1 | 4 |

### Interpretation

Adding the North Star Moment made the Coach Digest better at grounding its
reflection in something the person actually did for a Core Value. The version
with the moment won three times as often as it lost, and the whole
Persona-resampled range sits above zero, which meets this evaluation's
definition of an improvement. At +33.3 points the effect falls inside the 25–39
range that Feng et al. (2026) reported as a clear advantage, although their
judges were physicians rather than an AI.

The judge appears reliable enough to trust the direction of the result. It gave
the same verdict in both orders for 85% of weeks, and it showed no preference
for either position. Ten of the eleven disagreements were a tie in one order and
a preference in the other; only one pair reversed outright.

The pilot's much larger effect, +63.6, did not hold up. The five demo Personas
were written to showcase the product and may have been easier cases, so the
main run is the estimate to report.

The honesty rule is **not strictly met**. The version with the North Star
Moment was flagged twice and the version without it never, so the moment was
flagged more often. Neither flag was repeated when the same pair was shown in
the other order, so both are weak signals, but they describe exactly the risk
this check exists to catch: a supportive moment used to soften a Conflict. The
third example below shows one of them.

### Examples

These examples quote the generated Coach Digests and the judge's reasons. The
judge saw the two versions only as "Response 1" and "Response 2".

**The North Star Moment helped (Persona `e448979e`, week of 2025-03-17,
reminder mode).** The Core Value was "Having influence over how things go".
That week the person's mother-in-law reorganised the baby's wardrobe and threw
away clothes, and the person only said "okay, thank you". The North Star Moment
came from two days earlier: "I told him fine but I'm deciding the menu, not his
mother."

- **With the moment:** "Earlier, when Farhan suggested dinner with his cousin's
  family, you were clear: 'I'm deciding the menu, not his mother.'"
- **Without it:** "The doctor's reassurance and the response you received to
  your product posts both offered moments where your judgment was taken
  seriously."
- **Judge (both orders):** the version with the moment names something the
  person actually did, while the other "only mentions things that happened to
  her".

**The version without the moment was better (Persona `f6180c27`, week of
2025-07-07, encouragement mode).** The Core Value was "Being there for the
people closest to me". This week the person spent four hours colour-coding their
mother's medication schedule. The North Star Moment chose a line written later that
week about past decisions: "When Ba died and Ma needed
somewhere to go, I didn't hesitate."

- **With the moment:** it opens on that quotation and on past decisions, and
  mentions the medication work only as a cost.
- **Without it:** "Color-coding Ma's medication schedule and printing the times
  in large font took four hours... a practical way of being there for her."
- **Judge (both orders):** the version without the moment opens on "a specific
  action from this week", while the other "relies on earlier decisions and a
  general 'staying present for Ma'".

The selection experiment graded this quotation correct, yet a more concrete
action sat in the same week. A correct North Star Moment is not always the most
useful one for the Coach Digest.

**The moment was used to soften a Conflict (Persona `f418b74b`, week of
2025-09-15, encouragement mode).** The Core Value was "Enjoying life and
having fun". One Journal Entry, reviewed as a Conflict, described pausing to enjoy a chai and the
afternoon light, then catching themselves and opening a spreadsheet at once,
"like I'd been caught doing something wrong". The North Star Moment was a
weaker supportive moment: "After work I was too tired to cook so I ordered in
and ate on the couch watching something forgettable."

- **With the moment:** "you ordered in and ate on the couch... giving yourself a
  small pause when cooking felt beyond you. Earlier, after coffee and cricket,
  you also let yourself sit with the chai, the easy conversation, and the warm
  afternoon light."
- **Without it:** "eating egg curry slowly and noticing the kitchen smell gave
  you a small stretch of enjoyment without turning it into another task."
- **Judge:** it preferred the version without the moment in both orders. In one
  order it also flagged the version with the moment: it presents the chai
  moment as enjoyment and "leaves out that the person caught themselves and
  opened the spreadsheet right away, so the Conflict is recast as a supportive
  action".

This is the failure the honesty check targets. Once the prompt contained a
supportive moment, the Coach Digest gathered nearby moments into the same
positive story and dropped the part of the Journal Entry that went against the
Core Value.

### Caveats

- **AI review only.** An AI wrote the Journal Entries and the Coach Digests, and
  an AI judged them. Nothing here shows that real people find the Coach Digest
  more helpful.
- **One narrow criterion.** The judge compared only how well each Coach Digest
  grounds its reflection in the person's own supportive action. Tone,
  readability, and whether the reflection feels useful were not judged, and a
  Coach Digest built around a quotation it was given may score well on this
  criterion by design.
- **Correct quotations only.** The 72 weeks are the ones where the selection
  experiment confirmed the quotation as correct, itself an AI grading. It
  graded 14 of 86 scored final-set cards incorrect, and this run says nothing
  about the effect of a wrong quotation.
- **Selection model differs from the live one.** The quotations were chosen by
  `gpt-5.6-luna` in the selection experiment; live selection now uses
  `gpt-6-luna`, which has not been re-evaluated.
- **Thin coverage outside ordinary weeks.** 65 of 72 weeks had No Active Drift
  and 58 used encouragement mode. Seven Active Drift weeks and seven weeks each
  of reflection and reminder are too few to support conclusions, even though
  reminder won all seven.
- **Clustered data.** Weeks from the same Persona are related. The resampled
  range accounts for this, but 23 Personas is still a small sample.
- **Same-family judge and writer of the Journal Entries.** Claude wrote the
  synthetic Journal Entries and judged the Coach Digests. Both versions quote
  the same entries, so this should not favour either one.
- **Full-length evidence.** The main run gave the Coach Digest full Journal
  Entry quotations, as the live product does, while the pilot's saved demo
  inputs used quotations shortened to about 40 words.
